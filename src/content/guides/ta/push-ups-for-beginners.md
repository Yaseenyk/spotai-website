Push-up அடிப்படையானதாகத் தெரியும், அதுதான் பிரச்சனை. எளிதாகத் தெரிவதால், ஒன்றுகூடச் செய்ய முடியாத புதியவர்கள் வெட்கப்பட்டு அதை skip செய்கிறார்கள். தரையில் தொடங்க வேண்டியதில்லை. சரியான உயரத்தில் தொடங்கி, படிப்படியாகக் கீழே வர வேண்டும்.

## நல்ல push-up எப்படி இருக்கும்

சுவர் முதல் தரை வரை, ஒவ்வொரு நிலையிலும் இந்த checklist-ஐப் பயன்படுத்துங்கள்:

- **கைகள்** தோள்களை விடச் சற்று அகலமாக, மார்புக்குக் கீழே அல்லது சற்று வெளியே.
- **உடல் நேராக**, தலை முதல் குதிகால் வரை. இடுப்பு தொங்கக்கூடாது, பிட்டம் மேலே தூக்கக்கூடாது.
- **Core-ம் glutes-ம் இறுக்கமாக**, யாரோ வயிற்றில் குத்தப் போவது போல brace செய்வது போல.
- **முழங்கைகள்** உடலிலிருந்து சுமார் 45 டிகிரியில், பக்கவாட்டில் நேராக விரிக்காமல்.
- **முழு range:** மார்பு கைகளிலிருந்து சுமார் ஒரு முஷ்டி உயரத்துக்கு வர வேண்டும், பிறகு கைகள் நேராகும் வரை தள்ளுங்கள்.

தரையில் பாதி rep-ஐ விட, incline-ல் முழு rep அதிகப் பயனுள்ளது. சீக்கிரமே தரைக்குப் போக அவசரப்படாதீர்கள்.

## Incline ladder

கைகள் எவ்வளவு உயரமோ, push-up அவ்வளவு எளிது. ஜிம்மில் பல்வேறு உயரங்களில் பல பொருட்கள் இருக்கும், அதனால் இது எளிது.

| படி | கைகள் எங்கே | தோராயமான கடினம் |
| --- | --- | --- |
| 1 | சுவர் | மிக எளிது |
| 2 | மார்பு உயரத்தில் Smith machine bar அல்லது rack bar | ரொம்ப எளிது |
| 3 | இடுப்பு உயரத்தில் bar | எளிது |
| 4 | Flat bench அல்லது உறுதியான மேசை | மிதமானது |
| 5 | Aerobic step அல்லது தாழ்வான box | கடினம் |
| 6 | தரை | முழு push-up |

Smith machine அல்லது rack-ல் வைத்த barbell சிறந்தது, ஏனெனில் ஒவ்வொரு notch-ஆக இறக்கலாம். Bar பூட்டப்பட்டு, உருள முடியாமல் இருப்பதை உறுதி செய்யுங்கள்.

## உங்கள் தொடக்கப் படியைக் கண்டுபிடியுங்கள்

1. Arm circles, சில எளிய wall push-ups மூலம் தோள்களை warm up செய்யுங்கள்.
2. ஒரு படியைத் தேர்ந்தெடுத்து, முடிந்த அளவு நல்ல reps செய்யுங்கள்.
3. நல்ல form-உடன் **8 முதல் 12** வந்தால், அதுதான் உங்கள் தொடக்கப் படி.
4. 12-க்கு மேலா? ஒரு படி கீழே போங்கள். 8-க்குக் குறைவா? ஒரு படி மேலே போங்கள்.

உங்கள் படியையும் reps-ஐயும் குறித்து வையுங்கள். அதுதான் உங்கள் baseline.

## பத்து push-ups-க்கு 6 வார plan

வாரத்துக்கு இரண்டு மூன்று முறை, இடையில் ஒரு ஓய்வு நாளுடன் பயிற்சி செய்யுங்கள். Warm-up-க்குப் பின், session-ன் தொடக்கத்துக்கு அருகில் push-ups செய்யுங்கள்.

| வாரம் | Plan |
| --- | --- |
| 1 | தொடக்கப் படியில் 8–10 reps-ல் 3 sets, 60–90 வினாடி ஓய்வு |
| 2 | அதே படியில் 10–12 reps-ல் 3 sets |
| 3 | ஒரு படி இறங்குங்கள். 10 வரை, முடிந்த அளவு நல்ல reps-ல் 3 sets |
| 4 | அதே படி, 10–12 reps-ல் 3 sets இலக்கு. ஒரு படி கீழே மெதுவான negatives-ல் ஒரு set சேருங்கள்: இறக்க 3 வினாடி எடுத்து, பிறகு reset செய்யுங்கள் |
| 5 | இன்னொரு படி இறங்குங்கள். 8–10 reps-ல் 3 sets |
| 6 | Test: தரையில் push-ups, முடிந்த அளவு நல்ல reps |

வாரம் 6-க்குள் தரையை எட்ட முடியவில்லை என்றால் பரவாயில்லை. Ladder-ல் கீழே இறங்கிக்கொண்டே இருங்கள். சிலருக்கு அதிக நேரம் ஆகும், குறிப்பாக எடை அதிகமாக இருந்தால் அல்லது மேல் உடலுக்கு ஒருபோதும் பயிற்சி செய்யாதிருந்தால். வழிமுறை அதேதான்.

இது புதியவர்களுக்கான American College of Sports Medicine-ன் பொதுவான ஆலோசனையைப் பின்பற்றுகிறது: ஒரு set-க்குச் சுமார் 8–12 reps, வாரத்துக்கு இரண்டு மூன்று sessions, உடல் பழகும்போது கடினத்தில் சிறிய படிகள்.

## பொதுவான தவறுகள்

| தவறு | சரி செய்வது |
| --- | --- |
| இடுப்பு தொங்குவது | Glutes-ஐ இறுக்கி brace செய்யுங்கள், அல்லது ஒரு படி மேலே போங்கள் |
| பிட்டம் மேலே | இடுப்பைக் கீழே இறக்கி, தோள்கள், குதிகால்களுடன் ஒரே கோட்டில் வையுங்கள் |
| முழங்கைகள் 90 டிகிரிக்கு விரிவது | சுமார் 45 டிகிரிக்கு உள்ளே கொண்டுவாருங்கள் |
| தலை தரையை நோக்கித் தொங்குவது | கைகளுக்குச் சற்று முன்னால் ஒரு புள்ளியைப் பாருங்கள் |
| பாதி reps | Reps குறைந்தாலும், உயரமான படிக்குப் போனாலும், மார்பை முழுமையாக இறக்குங்கள் |

இடுப்பு தொங்குவதைக் கண்டுபிடிக்க எளிதான வழி பக்கவாட்டிலிருந்து பார்ப்பது. ஒரு set-ஐ வீடியோ எடுத்து, கீழ்நிலையில் pause செய்யுங்கள். எந்தப் போனிலும் இதைச் செய்யலாம், அல்லது SpotAI-ல் set-ஐ record செய்து உடனே திரும்பப் பார்க்கலாம்.

## உதவும் exercises

- **Plank:** 20–40 வினாடி 3 holds, உடல் அதே நேர் கோட்டில்.
- **Dumbbell அல்லது machine chest press:** மாற்றக்கூடிய எடையுடன் அதே தசைகளை வளர்க்கும். எங்கள் [bench press form](/ta/guides/bench-press-form-for-beginners/) வழிகாட்டி barbell வடிவத்தை விளக்குகிறது.
- **Triceps pushdowns:** வலுவான triceps, push-up-ன் மேல் பகுதியில் கைகளை lock out செய்ய உதவும்.

இவற்றில் எதற்கும் முன் warm up செய்யுங்கள்; [lifting-க்கு முன் warm up செய்வது எப்படி](/ta/guides/how-to-warm-up-before-the-gym/) பாருங்கள்.

## பத்துக்குப் பிறகு

பத்து நல்ல floor push-ups செய்ய முடிந்ததும், தொடர்ந்து வளருங்கள்: ஒரு set சேருங்கள், இறக்கும் பகுதியை மெதுவாக்குங்கள், அல்லது கால்களை ஒரு தாழ்வான step மேல் வையுங்கள். அதே விதி பொருந்தும். ஒவ்வொரு rep-ம் checklist போலவே இருக்கும் வரை மட்டும் கடினத்தைக் கூட்டுங்கள்.

தோள், முழங்கை அல்லது மணிக்கட்டில் குறையாத வலி இருந்தால், நிறுத்திவிட்டுத் தொடர்வதற்கு முன் மருத்துவரையோ physiotherapist-ஐயோ பாருங்கள்.
